# Styles

Styles in the Editor are standardized.

## Colors

Colors are always defined in hex codes.

### Defaults

Default Font: #000000
Default Background: #ffffff

### Toolbar & Sidebar

Blank background: #ffffff
Background: #eeeeee
Input Background: #dddddd

### Outlines

Hard Outline: #000000
Medium Outline: #575757
Soft Outline: #bababa

### Buttons

Hover: #3cb372cc
Selected: #84ecb3

### Editor

**Tables**

Table Outline: #cccccc
Table Head: #ebebeb
Table Cell: #ffffff

**Code**

Inline Code: #cdcdcd
Code Block Background: #222222
Code Block Font: #ffffff

## Styling

### Borders

**Large**

Width: 3px
Transparency: solid
Color: [Hard Outline](#outlines)
Radius: 8px

**Small**

Width: 2px
Transparency: solid
Color: [Hard Outline](#outlines)
Radius: 5px
