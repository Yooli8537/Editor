Save Config

Maximum name character count (characters)
Maximum amount of characters which a file / folder can have.
Default: 30
Autosave Interval (seconds)
Set the amount of time the server waits before attempting to create another autosave. Note that each autosave overwrites the previous one, so the cost of autosaving is mostly network traffic. Automatically rounded to the nearest 0.1s.
Default: 10s
Confirm Save
Whether or not clicking the save button will make you confirm your action.
Default: True

Sidebar

Name cutoff (characters)
Set how many characters it takes until a folder's or file's name is cut off on the sidebar. Note that very long names will cause issues with display and the filesystem.
Default: 20 characters

Editor

Help Text hover Time (seconds)
How long your mouse has to hover over a help text in order for it to appear. Automatically rounded to the nearest 0.1s.
Default: 1.5s

Storage

Clear unused Images
Searches through all your documents and removes any unused images from the server storage. This may take a while if you have a lot of documents.
Do not use this option while you have unsaved documents open, as the images in the unsaved document are supposed to stay but aren't referenced anywhere, so the server thinks that they're unused.

Automated Traffic

Update collapsed Folders (seconds)
Interval of saving the current collapsed folders to master.json for permanent storage.
Default: 15s

Welcome to the Server settings! In order to apply any updates, you must restart your server.

Server Logs

Save Logs to file
Controls if Server Logs are also saved to files under the "Editor/logs/" directory.
Default: False
Error Logs
Logs which give out any server errors.
Error Logs cannot be turned off.
Warning Logs
Logs which warn you if something could be going wrong.
Default: True
Success Logs
Logs which come out whenever an operation is completed successfully (such as renaming, creating a new file, etc.).
Default: True
Detailed Logs
Extra logs which give you additional information about what's going on under the hood.
Default: False
