Save Config

Autosave Interval (seconds)
Set the amount of time the server waits before attempting to create another autosave. Note that each autosave overwrites the previous one, so the cost of autosaving is mostly network traffic and not having enough storage for it. Automatically rounded to the nearest 0.1s.
Default: 10s

Storage

Clear unused Images
Searches through all your documents and removes any unused images from the server storage. This may take a while if you have a lot of documents.
