Info

Saving

Maximum name character count (characters)
Maximum amount of characters which a file / folder name can have.
Default: 30
Autosave Interval (seconds)
Set the amount of time the server waits before attempting to create another autosave. Note that each autosave overwrites the previous one, so the cost of autosaving is mostly network traffic. Automatically rounded to the nearest 0.1s.
Default: 10s
Confirm Save
Whether or not clicking the save button will make you confirm your action.
Default: True

Exports

Confirm Export
Whether or not exporting a document should require a confirmation.
Default: False

Collapsed Folders

Collapsed folder update method
How collapsed folders are updated. Note that automatic uses less resources when actively working on documents but still uses the same amount of resources whilst AFK. Manual mode may use more resources over a short burst, but is fully inactive when AFK.
Default: Automatic
Update collapsed Folders (seconds)
Interval of saving the current collapsed folders to master.json for permanent storage.
Default: 15s

Sidebar

Name cutoff (characters)
Set how many characters it takes until a folder's or file's name is cut off on the sidebar. Note that very long names will cause issues with display and the filesystem.
Default: 20 characters

Editor

Help Text hover Time (seconds)
How long your mouse has to hover over a help text in order for it to appear. Automatically rounded to the nearest 0.1s.
Default: 1.5s

Format settings affect only formats within the editor itself. All changes affect every document.

Storage

Maximum Image size (Megabytes)
Maximum file size which a single image uploaded to a document can be. Applying this setting requires a Server restart.
Default: 10mb
Clear unused Images
Searches through all your documents and removes any unused images from the server storage. This may take a while if you have a lot of documents.
Do not use this option while you have unsaved documents open, as the images in the unsaved document are supposed to stay but aren't referenced anywhere, so the server thinks that they're unused.
Clear Logs
Clears out all of the server logs, excluding the log from the current runtime (if enabled).

Welcome to the Server settings! In order to apply any updates, you must restart your server.

Rate Limiting

Rate Limiting blocks requests from a Client after a certain threshold is met. The limit is reset after a specified amount of time.
Note that if you set these limits too harshly, you could have a very hard time changing them back without editing the master.json file directly.
Restarting the Server will remove any rate limit applied to anyone.
Maximum number of requests
The maximum amount of requests which can be sent within the specified interval.
Default: 300 requests
Rate Limit reset time (minutes)
The interval at which the rate limit is reset back to 0. This doesn't mean that once you've sent X requests, you have to wait X minutes; instead, your request count resets every X minutes.
Default: 5 minutes

Server Logs

Save Logs to file
Controls if Server Logs are also saved to files under the "Editor/logs/" directory.
Default: False
Error Logs
Logs which give out any server errors.
Error Logs cannot be turned off.
Detailed Error logs
Gives out more detail from errors. Note that not every error will have additional details.
Default: False
Warning Logs
Logs which warn you if something could be going wrong.
Default: True
Success Logs
Logs which come out whenever an operation is completed successfully (such as renaming, creating a new file, etc.).
Default: True
Detailed Logs
Extra logs which give you additional information about what's going on under the hood.
Default: False
